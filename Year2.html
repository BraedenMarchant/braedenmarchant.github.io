Custom 75mm FPV Drone **WIP**

A custom built 75mm FPV drone. Built with betaFPV 5in1 flight controller and programmed in Betaflight.

Overview

I am currently working on building a 75mm FPV Drone. During this project I will focus on my electronics skills and working with RF. The plan for this project is to first create a drone with an existing flight controller, but in the future I would like to design my own.

Design

The plan for this project is to first create a drone using an exisiting flight controller and frame. Once done, I will move to design my own flight controller and 3D-print the frames with a lightweight PLA filament.
